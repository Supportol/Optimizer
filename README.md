**Оптимайзер** — небольшая программа: удаляет кэши и временные файлы, включает понятные настройки для игр и системы и **запоминает, как было**, чтобы можно было вернуть.

| | |
|---|---|
| Раздача | один файл `Optimizer.exe` |
| Установка | не нужна |
| Сеть | ничего не скачивает |
| Язык | русский по умолчанию, в шапке — English |
| Права | администратор (запрос UAC при запуске) |
| Автор | Supportol |

Не активирует Windows. Не ставит ключи. Не лечит вирусы и не разгоняет видеокарту.

## Зачем это

Типичный «твикер» жмёт одну кнопку и ломает сеть. Здесь наоборот:

1. Каждая очистка — **своя кнопка**, видно размер до удаления.
2. Каждый твик — **свой тумблер**. Включили — применилось. Выключили — откатилось.
3. На кружке **i** написано, что именно изменится.
4. Вкладка **Откат** хранит снимки реестра и служб.

Документы, фото, установленные игры и Program Files программа не трогает.

## Что внутри

### Очистка

Сначала **Сканировать размеры** (ничего не удаляет), затем «Очистить» у нужной строки. Занятые файлы пропускаются.

| Категория | Что удаляется | Что остаётся |
|---|---|---|
| Временные файлы | черновики программ, `%TEMP%` | документы |
| Корзина | содержимое корзины на дисках | — (уже не восстановить из корзины) |
| Превью папок и фото | кэш значков | сами фото |
| Отчёты о сбоях | дампы, WER | система |
| Журналы | текстовые логи Windows | драйверы |
| Кэш обновлений | скачанные куски Windows Update | установленные обновления |
| Браузеры | Cache / GPUCache Chrome, Edge, Firefox, Vivaldi… | закладки, пароли |
| Мессенджеры | кэш Discord, Telegram, Teams, Slack, Spotify | чаты и вход |
| Графика игр | шейдеры NVIDIA / AMD / DirectX | игры и сохранения; первый запуск может подлагивать |
| Steam / лаунчеры | http-кэш, webcache Epic, EA, Ubisoft, Riot, GOG | игры |
| Prefetch | кэш запуска программ | лучше чистить редко |
| Xbox, Store, шрифты | служебный кэш | приложения и файлы шрифтов |
| Дамп памяти | `MEMORY.DMP` после синего экрана | — |
| Недавние файлы | список в проводнике | сами файлы |
| WebView, Office, OBS, Защитник | кэш WebView2, OfficeFileCache, логи OBS, история сканов | документы, карантин, записи OBS |

### Игры, система, сеть, приватность

Не «оптимизировать всё», а отдельные тумблеры и ползунки.

- **Вкл** — текущее значение запоминается, настройка применяется.
- **Выкл** — возвращается запомненное.
- Ползунок срабатывает, когда **отпускаете** мышь.
- Часть пунктов просит перезагрузку — это видно в статусе внизу.

Примеры: игровой режим, без записи Xbox, планировщик GPU, план питания, мышь без ускорения, меньше телеметрии, DNS 1.1.1.1, без рекламы в проводнике.

На **Сети** есть разовые кнопки: сброс DNS / ARP / NetBIOS, оптимизация TCP, обновление IP, сброс Winsock (два последних — с подтверждением).

### Вкладки Windows 10 и Windows 11

Свои пункты под каждую систему. Сборка **22000+** считается Windows 11. На «чужой» вкладке показывается предупреждение: включать можно, часто эффекта не будет.

**Windows 10:** новости в панели, Meet Now, People, живые плитки, Кортана на панели, «Объёмные объекты», планшетный режим, Aero Peek.

**Windows 11:** панель слева, классическое меню ПКМ, виджеты, Copilot, чат Teams, рекомендации в Пуске, Recall, компактный проводник, «Снять задачу» из панели.

После сдвига панели или классического меню: вкладка **Сервис** → перезапуск проводника.

### Сервис

Разовые действия **без снимка в откате**:

- перезапуск проводника
- сборка кэша значков
- очистка очереди печати
- сброс кэша Microsoft Store
- TRIM системного диска
- перезапуск службы звука

### Откат

Список снимков: последнее изменение, выбранный пункт или всё сразу.

Путь:

```text
%ProgramData%\WinOptimizer\backups
```

Удалённые кэши и кнопки «Сервиса» сюда **не** попадают — кэши Windows создаст снова.

### Окно

Без стандартной рамки: свернуть / на весь экран / закрыть в шапке. Края окна можно тянуть (в полноэкранном режиме — нельзя). RU | EN — переключатель языка.

## Как пользоваться

1. Скачайте [`Optimizer.exe`](Optimizer.exe) из корня репозитория.
2. Запустите и подтвердите UAC.
3. Прочитайте предупреждение (можно больше не показывать).
4. **Очистка** → сканировать → чистить по одной категории.
5. Тумблеры — только то, что понимаете. Неясно — наведите на **i**.
6. Стало хуже — выключите тумблер или вкладка **Откат**.
7. После очистки шейдеров первый запуск игры может подлагивать — так и должно быть.

## Требования

- Windows 10 или Windows 11
- .NET Framework 4.x (уже есть в системе)
- права администратора
- разрешение UAC

Не работает как антивирус, не ускоряет железо само по себе, на старых видеокартах часть игровых пунктов может ничего не менять.

## Данные на диске

| Файл | Зачем |
|---|---|
| `%ProgramData%\WinOptimizer\lang.txt` | `ru` или `en` |
| `%ProgramData%\WinOptimizer\backups\` | JSON-снимки твиков |
| `%ProgramData%\WinOptimizer\disclaimer.skip` | больше не показывать предупреждение |

Удаление этой папки сбрасывает язык и список отката. Сама Windows от этого не ломается.

## Чего программа не делает

- не активирует Windows и не подбирает ключи
- не удаляет личные документы и установленные программы
- не чистит карантин Защитника
- не отключает Защитник, брандмауэр и UAC
- не ставит драйверы и не качает пакеты из сети

## English

**Optimizer** is a small Windows 10/11 tool: junk cleanup, per-toggle tweaks with restore, no installer. One `Optimizer.exe`. Default UI language is Russian; switch to English in the title bar. Administrator / UAC required.

Cleanup never touches Documents, photos, installed games, or Program Files. Busy files are skipped. Toggles save the previous value; turn them off to restore. The **Restore** tab lists snapshots under `%ProgramData%\WinOptimizer\backups`. Cache deletes and Tools-tab actions are not in that list.

There are separate **Windows 10** and **Windows 11** tabs. Build 22000+ is treated as Windows 11.

This program does not activate Windows, does not disable Defender, and does not download extra runtimes.

Download [`Optimizer.exe`](Optimizer.exe) from the repo root. Version **1.6.2**. Developer: **Supportol**.
