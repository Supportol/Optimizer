# Оптимайзер

Очистка мусора и безопасные твики для **Windows 10 и 11**, с откатом настроек.

Один файл. Без установщика. Ничего не скачивает.

[![UAC](https://img.shields.io/badge/права-администратор-3EB489)](https://github.com/Supportol/Optimizer)

**Скачать программу:** [Optimizer.exe](./Optimizer.exe)

Язык по умолчанию — русский, в шапке окна можно включить English. Нужен запрос UAC.

Не активирует Windows. Не ставит ключи. Не лечит вирусы и не разгоняет видеокарту.

## Зачем это

Обычный твикер жмёт одну кнопку и может сломать сеть. Здесь иначе:

1. Каждая очистка — своя кнопка, размер видно до удаления.
2. Каждый твик — свой тумблер. Включили — применилось. Выключили — откатилось.
3. На кружке **i** написано, что изменится.
4. Вкладка **Откат** хранит снимки реестра и служб.

Документы, фото, установленные игры и Program Files не трогаются.

## Очистка

Сначала **Сканировать размеры** (ничего не удаляет), затем «Очистить» у нужной строки. Занятые файлы пропускаются.

| Категория | Что удаляется | Что остаётся |
| --- | --- | --- |
| Временные файлы | черновики программ, `%TEMP%` | документы |
| Корзина | содержимое корзины | восстановить из корзины уже нельзя |
| Превью папок и фото | кэш значков | сами фото |
| Отчёты о сбоях | дампы, WER | система |
| Журналы | текстовые логи Windows | драйверы |
| Кэш обновлений | куски Windows Update | установленные обновления |
| Браузеры | кэш Chrome, Edge, Firefox, Vivaldi | закладки, пароли |
| Мессенджеры | кэш Discord, Telegram, Teams, Slack, Spotify | чаты и вход |
| Графика игр | шейдеры NVIDIA / AMD / DirectX | игры и сохранения |
| Steam и лаунчеры | веб-кэш Epic, EA, Ubisoft, Riot, GOG | игры |
| Prefetch | кэш запуска программ | лучше чистить редко |
| Xbox, Store, шрифты | служебный кэш | приложения и шрифты |
| Дамп памяти | `MEMORY.DMP` после синего экрана | — |
| Недавние файлы | список в проводнике | сами файлы |
| WebView, Office, OBS, Защитник | кэш и логи | документы, карантин, записи OBS |

После очистки шейдеров первый запуск игры может подлагивать — так и должно быть.

## Твики

Вкладки **Игры**, **Система**, **Сеть**, **Приватность** — отдельные тумблеры и ползунки.

- **Вкл** — старое значение запоминается, настройка применяется.
- **Выкл** — возвращается запомненное.
- Ползунок срабатывает, когда отпускаете мышь.
- Часть пунктов просит перезагрузку — это видно в статусе внизу.

Примеры: игровой режим, без записи Xbox, план питания, мышь без ускорения, меньше телеметрии, DNS 1.1.1.1.

На **Сети** есть кнопки: сброс DNS / ARP / NetBIOS, оптимизация TCP, обновление IP, сброс Winsock (два последних — с подтверждением).

## Windows 10 и 11

Свои пункты под каждую систему. Сборка **22000+** считается Windows 11.

**Windows 10:** новости в панели, Meet Now, People, живые плитки, Кортана, «Объёмные объекты», планшетный режим.

**Windows 11:** панель слева, классическое меню ПКМ, виджеты, Copilot, чат Teams, рекомендации в Пуске, Recall.

После сдвига панели или классического меню откройте **Сервис** и перезапустите проводник.

## Сервис

Разовые действия без снимка в откате:

- перезапуск проводника
- сборка кэша значков
- очистка очереди печати
- сброс кэша Microsoft Store
- TRIM системного диска
- перезапуск звука

## Откат

Можно вернуть последнее изменение, выбранный снимок или всё сразу.

Снимки лежат здесь:

```text
%ProgramData%\WinOptimizer\backups
```

Удалённые кэши и кнопки «Сервиса» в этот список не входят.

Окно без рамки: свернуть, на весь экран, закрыть. Края можно тянуть. Язык RU / EN — в шапке.

## Как пользоваться

1. Скачайте [Optimizer.exe](./Optimizer.exe).
2. Запустите и подтвердите UAC.
3. Прочитайте предупреждение.
4. На **Очистке** сначала сканируйте, потом чистите по одной категории.
5. Тумблеры включайте только если понимаете пункт. Неясно — наведите на **i**.
6. Если стало хуже — выключите тумблер или откройте **Откат**.

## Требования

- Windows 10 или Windows 11
- .NET Framework 4.x (уже есть в системе)
- права администратора

Не антивирус и не разгон железа. На старых видеокартах часть игровых пунктов может ничего не менять.

## Данные на диске

| Файл | Зачем |
| --- | --- |
| `%ProgramData%\WinOptimizer\lang.txt` | язык `ru` или `en` |
| `%ProgramData%\WinOptimizer\backups\` | снимки твиков |
| `%ProgramData%\WinOptimizer\disclaimer.skip` | больше не показывать предупреждение |

Удаление этой папки сбрасывает язык и список отката. Windows от этого не ломается.

---

## Чего программа не делает

- не активирует Windows и не подбирает ключи
- не удаляет личные документы и установленные программы
- не чистит карантин Защитника
- не отключает Защитник, брандмауэр и UAC
- не ставит драйверы и не качает пакеты из сети

## English

**Optimizer** is a small Windows 10/11 tool: junk cleanup, per-toggle tweaks with restore, no installer.

Download [Optimizer.exe](./Optimizer.exe). Default language is Russian; switch to English in the title bar. Administrator / UAC required.

Cleanup never touches Documents, photos, installed games, or Program Files. Turn a toggle off to restore. Snapshots: `%ProgramData%\WinOptimizer\backups`.

This program does not activate Windows and does not disable Defender.
